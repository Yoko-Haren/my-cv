## 📖 About This Project

This repository serves as an introductory project for building and managing
a personal web presence using modern development tools. It combines essential
version control practices with fundamental web development concepts to
produce a clean, accessible, and responsive CV webpage.

The primary objectives of this project are:

- To gain hands-on experience with **Git** and **GitHub** workflows.
- To apply **HTML5** and **CSS3** in building a structured, responsive layout.
- To develop an understanding of professional project organization and documentation.
